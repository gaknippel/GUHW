\section*{Question 2}

threshold: border length $> 400$ (same as hw3 query 8).

\subsection*{output (hw4, using border\_full)}
{\small
\begin{verbatim}
 country_code |       country_name
--------------+--------------------------
 CA           | Canada
 US           | United States of America
(2 rows)
\end{verbatim}
}

\subsection*{output (hw3 query 8, same starting data)}
{\small
\begin{verbatim}
 country_code |       country_name
--------------+--------------------------
 CA           | Canada
 US           | United States of America
(2 rows)
\end{verbatim}
}

\subsection*{comparison}
both queries return the same rows: US and CA. the US has a higher gdp (46900 $>$ 15300) and
lower inflation (3.8 $<$ 4.7) than MX, and it borders with length 3145 $> 400$.
CA has a higher gdp (43100 $>$ 15300) and lower inflation (2.4 $<$ 4.7) than MX, which it
borders with length 500 $> 400$. the hw3 query needed \texttt{OR} to check both columns of
\texttt{border}, but \texttt{border\_full} already has both directions, so the hw4 query only
checks \texttt{country\_code\_1}.

\section*{Question 3}

\subsection*{output}
{\small
\begin{verbatim}
 country_code | country_name
--------------+--------------
 DE           | Germany
 IS           | Iceland
(2 rows)
\end{verbatim}
}

\subsection*{examples}
relevant stored rows:
{\small
\begin{verbatim}
country: ('DE', 'Germany', 52100, 2.2)
         ('US', 'United States of America', 46900, 3.8)
border:  ('MX', 'US', 3145)
         ('US', 'CA', 8891)
         ('CA', 'MX', 500)
\end{verbatim}
}

\noindent\textbf{matching:} DE has no rows in \texttt{border}, so it never appears as
\texttt{country\_code\_1} in \texttt{border\_full}. it is not removed by the \texttt{EXCEPT}
and shows up in the result.

\noindent\textbf{nonmatching:} US is in the stored row
\texttt{('MX', 'US', 3145)}, so \texttt{border\_full} has a row with \texttt{country\_code\_1 = 'US'}.
the second half of the \texttt{EXCEPT} returns US, so it is removed.

\section*{Question 5}

\subsection*{output}
{\small
\begin{verbatim}
 country_code | country_name |  gdp
--------------+--------------+-------
 DE           | Germany      | 52100
 IS           | Iceland      | 52100
(2 rows)
\end{verbatim}
}

\subsection*{examples}
relevant stored rows:
{\small
\begin{verbatim}
country: ('DE', 'Germany', 52100, 2.2)
         ('IS', 'Iceland', 52100, 3.1)
         ('US', 'United States of America', 46900, 3.8)
\end{verbatim}
}

\noindent\textbf{matching:} DE and IS both have gdp 52100. no country has a higher gdp,
so the join \texttt{c1.gdp < c2.gdp} never matches them, they are not removed by the
\texttt{EXCEPT}, and both are returned (a tie).

\noindent\textbf{nonmatching:} US has gdp 46900, which is lower than DE's 52100, so the join matches US
and it is removed by the \texttt{EXCEPT}.
