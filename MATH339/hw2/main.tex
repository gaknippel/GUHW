\section*{Section 1.3 \#27}

Find all $2 \times 2$ matrices of the form
\[
A = \begin{pmatrix} a & b \\ 0 & c \end{pmatrix}
\]
such that
\[
A^2 = AA = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}.
\]

solving $A^2$,
\[
A^2 = \begin{pmatrix} a & b \\ 0 & c \end{pmatrix}\begin{pmatrix} a & b \\ 0 & c \end{pmatrix} = \begin{pmatrix} a^2 & b(a+c) \\ 0 & c^2 \end{pmatrix}.
\]
set this answer equal to $I$ 
\[
a^2 = 1, \qquad c^2 = 1, \qquad b(a+c) = 0.
\]
the first two equations give us $a = \pm 1$ and $c = \pm 1$. and for the third equation, if $a = c$ then $a + c \neq 0$, so $b = 0$; if $a \neq c$ then $a + c = 0$ automatically, so $b$ has got to be any real number. this gives all solutions:
\[
A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}, \qquad
A = \begin{pmatrix} -1 & 0 \\ 0 & -1 \end{pmatrix}, \qquad
A = \begin{pmatrix} 1 & b \\ 0 & -1 \end{pmatrix},\ b \in \mathbb{R}, \qquad
A = \begin{pmatrix} -1 & b \\ 0 & 1 \end{pmatrix},\ b \in \mathbb{R}.
\]
